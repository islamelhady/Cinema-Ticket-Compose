# Cinema Ticket Booking UI 🎬

A simple project built with **Jetpack Compose** featuring user interfaces for a modern Cinema Ticket Booking experience.

> **Note:** This is a **UI-only** project, designed to showcase layout skills and component distribution in Compose.
